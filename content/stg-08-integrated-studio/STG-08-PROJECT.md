# STG-08-PROJECT — مشروع المرحلة الثامنة

> **Content Package:** `project-STG08-v1.0.0` · **Type:** Stage project (AT-05) · **Difficulty:** A3
> **Config:** تقييم بسُلَّم 4 معايير (DOC-08 §6) · النجاح: متوسط ≥ 3.0/4 وعدم وجود أي معيار بدرجة 1 · محاولتان بفاصل 3 أيام

## 1. نبذة المشروع

مشروع المرحلة الثامنة هو **مشروع عميل متكامل عبر التطبيقات** يجمع كل ما تعلمته في الدورة. تنتج هوية بصرية كاملة لشركة ناشئة (من الشعار إلى الطباعة إلى الفيديو إلى المجلة) مع مكتبات مشتركة وتوثيق دراسة حالة للبورتفوليو — كما اختتم في LES-080305.

**الفكرة:** مشروع واقعي يحاكي سير عمل عميل حقيقي باستخدام كل تطبيقات أدوبي (فوتوشوب + إليستريتور + أفتر إفكتس + بريميير + لايتروم + إن ديزاين) مع تسليم مهني كامل.

## 2. المطلوب (Brief)

| # | التسليم | الوصف | المصدر |
|---|---------|-------|--------|
| 1 | `client-brief.md` | موجز العميل الأصلي + تحليلك وترجمته إلى متطلبات | LES-080201, LES-080202 |
| 2 | `integrated-brand-kit.zip` | مكتبة هوية مشتركة (شعار AI + ألوان + خطوط + أنماط + مكتبة CC) | LES-080101, LES-080103, LES-080301 |

## 3. سُلَّم التقييم (Rubric)

| المعيار | 4 (ممتاز) | 3 (جيد جدًا) | 2 (مقبول) | 1 (غير مكتمل) |
|---------|-----------|--------------|-----------|----------------|
| **الالتزام بالموجز** | كل التسليمات الستة كاملة ومترابطة عبر التطبيقات مع مكتبة CC موحدة | التسليمات كاملة مع فجوة ترابط بسيطة | تسليم ناقص واحد أو ترابط ضعيف | أكثر من تسليم ناقص أو خارج الموجز |
| **التقنية والمهارة** | تطبيق دقيق للتكامل متعدد التطبيقات + المكتبات المشتركة + التصدير المهني + إدارة العملاء | تطبيق صحيح مع أخطاء طفيفة | تطبيق جزئي للتقنيات | غياب واضح للتكامل والتقنيات |
| **الجودة البصرية** | مشروع متكامل احترافي متناسق عبر كل الوسائط | جيدة مع بعض العيوب البصرية | مقبولة بلا تناسق كبير | مشروع غير مكتمل أو رديء |
| **التقديم والتوثيق** | دراسة حالة كاملة + تسليم مهني + عقود + CREDITS دقيق | تسليم كامل مع نقص بسيط في التوثيق | تسليم ناقص أو توثيق ضعيف | غياب التوثيق أو التسليم المهني |

## 4. معايير المراجعة الذاتية (قبل التسليم)

- [ ] التسليمات الستة موجودة بالأسماء الصحيحة وفي مجلد `08-التسليم`.
- [ ] الموجز يحتوي تحليلًا واضحًا ومتطلبات محددة.
- [ ] المكتبة المشتركة (CC Libraries) تحتوي كل العناصر القابلة لإعادة الاستخدام.
- [ ] الأصول تعمل عبر التطبيقات (Linked Smart Objects + Libraries).
- [ ] العرض التقديمي يوضح العملية والنتائج للعميل.
- [ ] دراسة الحالة توثق كل القرارات والتحديات.
- [ ] التسليم المهني يشمل عقودًا وCREDITS وprocess-log.
- [ ] كل الملفات منظمة وجاهزة للتسليم للعميل.

## 5. إجراءات التسليم

1. جهّز مجلد `08-التسليم` في مشروعك وضع فيه التسليمات الستة + مجلد فرعي `assets`.
2. قدّم رابط/ملفات التسليم عبر منصة التعلم (SCR-11).
3. ستُراجع أعمالك وفق السُلَّم أعلاه خلال 72 ساعة (DOC-08 §8).
4. في حال الإعادة: عالج الملاحظات وقدّم نسخة V2 خلال 3 أيام (DOC-08 §5).
