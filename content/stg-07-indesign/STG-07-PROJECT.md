# STG-07-PROJECT — مشروع المرحلة السابعة

> **Content Package:** `project-STG07-v1.0.0` · **Type:** Stage project (AT-05) · **Difficulty:** A2
> **Config:** تقييم بسُلَّم 4 معايير (DOC-08 §6) · النجاح: متوسط ≥ 3.0/4 وعدم وجود أي معيار بدرجة 1 · محاولتان بفاصل 3 أيام

## 1. نبذة المشروع

مشروع المرحلة السابعة يتوّج تعلمك لإن ديزاين بإنتاج **عدد مجلة عربية مصغر (8–12 صفحة)**. يشمل الشبكة التحريرية، الماسترز، الأنماط، المحتوى، الفحص المسبق، التغليف، والنسخة الرقمية — كما اختتم في LES-070402.

**الفكرة:** تنتج مجلة مترابطة بصريًا (شبكة + أنماط + طباعة عربية) جاهزة للطباعة والنشر الرقمي.

## 2. المطلوب (Brief)

| # | التسليم | الوصف | المصدر |
|---|---------|-------|--------|
| 1 | `magazine-master.indd` | مستند رئيسي (Master Pages) + شبكة تحريرية (12 عمود + baseline) + أنماط فقرات/حروف | LES-070101, LES-070103, LES-070104, LES-070201 |
| 2 | `magazine-content.indd` | 8–12 صفحة محتوى (مقالات + صور + جداول + رسوم) مع تدفق نصي عربي | LES-070105, LES-070202, LES-070203 |
| 3 | `magazine-interactive.pdf` | نسخة PDF تفاعلية (روابط + نماذج + طبقات) | LES-070204 |
| 4 | `magazine-preflight-report.pdf` | تقرير الفحص المسبق + إصلاحات + مواصفات طباعة (CMYK/Spot) | LES-070301, LES-070303 |
| 5 | `magazine-print-package.zip` | مجلد التغليف الكامل (INDD + Links + Fonts + PDF/X-4) | LES-070302 |
| 6 | `magazine-digital.zip` | نسخة رقمية (Publish Online + EPUB + Liquid Layout) + CREDITS + process-doc.pdf | LES-070401, LES-070402 |

> يجب أن تكون المجلة مترابطة (نفس الشبكة والأنماط) وتدعم اللغة العربية بقوة (من اليمين إلى اليسار).

## 3. سُلَّم التقييم (Rubric)

| المعيار | 4 (ممتاز) | 3 (جيد جدًا) | 2 (مقبول) | 1 (غير مكتمل) |
|---------|-----------|--------------|-----------|----------------|
| **الالتزام بالموجز** | كل التسليمات الستة كاملة ومترابطة بصريًا مع شبكة وأنماط موحدة | التسليمات كاملة مع فجوة ترابط بسيطة | تسليم ناقص واحد أو ترابط ضعيف | أكثر من تسليم ناقص أو خارج الموجز |
| **التقنية والمهارة** | تطبيق دقيق للشبكة + الماسترز + الأنماط + الفحص المسبق + التغليف + النشر الرقمي | تطبيق صحيح مع أخطاء طفيفة | تطبيق جزئي للتقنيات | غياب واضح للتقنيات الأساسية |
| **الجودة البصرية** | تصميم تحريري احترافي متناسق الطباعة والصور | جيدة مع بعض العيوب البصرية | مقبولة بلا تناسق كبير | تصميم غير مكتمل أو رديء |
| **التقديم والتوثيق** | تسليم مهني كامل + وثيقة عملية مفصلة + CREDITS دقيق | تسليم كامل مع نقص بسيط في التوثيق | تسليم ناقص أو توثيق ضعيف | غياب التسليم أو التوثيق |

## 4. معايير المراجعة الذاتية (قبل التسليم)

- [ ] التسليمات الستة موجودة بالأسماء الصحيحة وفي مجلد `07-التسليم`.
- [ ] الماسترز والشبكة التحريرية (12 عمود) مطبقة على كل الصفحات.
- [ ] الأنماط (فقرات/حروف) موحدة وتدعم النص العربي.
- [ ] المحتوى يتدفق بشكل صحيح ويحتوي جداول ورسوم.
- [ ] الفحص المسبق ناجح ومواصفات الطباعة موثقة.
- [ ] التغليف يشمل كل الروابط والخطوط.
- [ ] النسخة الرقمية جاهزة (Publish Online + EPUB).
- [ ] process-doc.pdf يوثق سير العمل والقرارات.

## 5. إجراءات التسليم

1. جهّز مجلد `07-التسليم` في مشروعك وضع فيه التسليمات الستة + مجلد فرعي `assets`.
2. قدّم رابط/ملفات التسليم عبر منصة التعلم (SCR-11).
3. ستُراجع أعمالك وفق السُلَّم أعلاه خلال 72 ساعة (DOC-08 §8).
4. في حال الإعادة: عالج الملاحظات وقدّم نسخة V2 خلال 3 أيام (DOC-08 §5).
