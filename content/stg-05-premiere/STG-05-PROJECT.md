# STG-05-PROJECT — مشروع المرحلة الخامسة

> **Content Package:** `project-STG05-v1.0.0` · **Type:** Stage project (AT-05) · **Difficulty:** I1
> **Config:** تقييم بسُلَّم 4 معايير (DOC-08 §6) · النجاح: متوسط ≥ 3.0/4 وعدم وجود أي معيار بدرجة 1 · محاولتان بفاصل 3 أيام

## 1. نبذة المشروع

مشروع المرحلة الخامسة يتوّج تعلمك لبريميير برو بإنتاج **قصة فيديو كاملة (60–90 ثانية)** لعلامة أو منتج. يشمل فرز اللقطات، القص، تصحيح الألوان، خلط الصوت، العناوين العربية، والتصدير المهني — كما اختتم في LES-050404.

**الفكرة:** تنتج فيديو مترابطًا يروي قصة بصرية قصيرة باستخدام تقنيات التحرير المتقدمة والتكيف للمنصات العربية.

## 2. المطلوب (Brief)

| # | التسليم | الوصف | المصدر |
|---|---------|-------|--------|
| 1 | `story-raw-footage-log.xlsx` | سجل فرز وتصنيف اللقطات (معدل إطارات، دقة، ملاحظات) + bin منظم | LES-050101, LES-050103 |
| 2 | `story-edit-sequence.prproj` | تسلسل مونتاج كامل (قص فني + انتقالات + multicam إن وجد) | LES-050201, LES-050202, LES-050203, LES-050205 |
| 3 | `story-color-audio.prproj` | نسخة مكتملة بتصحيح Lumetri + خلط صوت احترافي + عناوين عربية | LES-050301, LES-050302, LES-050303 |
| 4 | `story-final-export.mp4` | النسخة النهائية (H.264 + ProRes) + ملفات XML للتصدير | LES-050401 |
| 5 | `story-thumbnails-pack.zip` | 5 صور مصغرة + وصف + كلمات مفتاحية عربية | LES-050402 |
| 6 | `story-delivery-package.zip` | مجلد تسليم كامل: PRPROJ + MP4 + XML + CREDITS + process-doc.pdf | LES-050403, LES-050404 |

> يجب أن تكون القصة مترابطة (سرد بصري واضح) ومُحسّنة للمنصات العربية (نسب 9:16 + 16:9).

## 3. سُلَّم التقييم (Rubric)

| المعيار | 4 (ممتاز) | 3 (جيد جدًا) | 2 (مقبول) | 1 (غير مكتمل) |
|---------|-----------|--------------|-----------|----------------|
| **الالتزام بالموجز** | كل التسليمات الستة كاملة ومترابطة سرديًا مع نسب متعددة | التسليمات كاملة مع فجوة ترابط بسيطة | تسليم ناقص واحد أو ترابط ضعيف | أكثر من تسليم ناقص أو خارج الموجز |
| **التقنية والمهارة** | تطبيق دقيق للقص + Lumetri + خلط الصوت + العناوين + التصدير المتعدد | تطبيق صحيح مع أخطاء طفيفة | تطبيق جزئي للتقنيات | غياب واضح للتقنيات الأساسية |
| **الجودة البصرية** | مونتاج سلس + ألوان متناسقة + صوت واضح | جيدة مع بعض العيوب في التوقيت أو اللون | مقبولة بلا سلاسة كبيرة | فيديو غير مكتمل أو رديء |
| **التقديم والتوثيق** | تسليم مهني كامل + وثيقة عملية مفصلة + CREDITS دقيق | تسليم كامل مع نقص بسيط في التوثيق | تسليم ناقص أو توثيق ضعيف | غياب التسليم أو التوثيق |

## 4. معايير المراجعة الذاتية (قبل التسليم)

- [ ] التسليمات الستة موجودة بالأسماء الصحيحة وفي مجلد `05-التسليم`.
- [ ] سجل الفرز يغطي كل اللقطات ويحدد الجيد منها.
- [ ] التسلسل يحتوي قصًا فنيًا + انتقالات + multicam إن أمكن.
- [ ] تصحيح الألوان Lumetri وخلط الصوت واضحان.
- [ ] العناوين العربية متناسقة مع الهوية البصرية.
- [ ] التصدير يشمل صيغ متعددة (H.264 + ProRes).
- [ ] الصور المصغرة جاهزة للنشر مع وصف عربي.
- [ ] process-doc.pdf يوثق سير العمل والقرارات.

## 5. إجراءات التسليم

1. جهّز مجلد `05-التسليم` في مشروعك وضع فيه التسليمات الستة + مجلد فرعي `assets`.
2. قدّم رابط/ملفات التسليم عبر منصة التعلم (SCR-11)。
3. ستُراجع أعمالك وفق السُلَّم أعلاه خلال 72 ساعة (DOC-08 §8).
4. في حال الإعادة: عالج الملاحظات وقدّم نسخة V2 خلال 3 أيام (DOC-08 §5).
