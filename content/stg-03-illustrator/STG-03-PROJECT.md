# STG-03-PROJECT — مشروع المرحلة الثالثة

> **Content Package:** `project-STG03-v1.0.0` · **Type:** Stage project (AT-05) · **Difficulty:** A2
> **Config:** تقييم بسُلَّم 4 معايير (DOC-08 §6) · النجاح: متوسط ≥ 3.0/4 وعدم وجود أي معيار بدرجة 1 · محاولتان بفاصل 3 أيام

## 1. نبذة المشروع

مشروع المرحلة الثالثة يجمع مهارات إليستريتور في إنتاج **هوية بصرية متكاملة لمتجر** (مقهى أو متجر إلكتروني أو علامة محلية). يشمل الشعار، نظام الألوان والطباعة، التطبيقات على الوسائط المختلفة، والتصدير الاحترافي للطباعة والويب — كما اختتم في LES-030406.

**الفكرة:** تنتج مجموعة ملفات مترابطة (شعار + دليل هوية + تطبيقات) تُظهر إتقانك للمتجهات، الطباعة، والأنماط.

## 2. المطلوب (Brief)

| # | التسليم | الوصف | المصدر |
|---|---------|-------|--------|
| 1 | `store-logo-final.ai` | شعار متجهي كامل (نسخة أساسية + نسخة أحادية اللون + نسخة أفقية) باستخدام شبكة هندسية ومنهجية التصميم | LES-030301, LES-030302, LES-030305 |
| 2 | `brand-identity-guide.pdf` | دليل هوية بصرية (8 صفحات): الشعار + لوحة ألوان + خطوط + أنماط + استخدامات محظورة | LES-030303, LES-030304 |
| 3 | `brand-applications-pack.zip` | تطبيقات الهوية: بطاقة عمل + كيس تسوق + لافتة + ملصق + قالب وسائل التواصل | LES-030204, LES-030401, LES-030406 |
| 4 | `print-export-package.zip` | ملفات جاهزة للطباعة (CMYK + Spot) + ملفات ويب (SVG/PNG) + دليل التصدير | LES-030403, LES-030405 |
| 5 | `brand-automation.ai` | ملف يحتوي أنماط وأشكال قابلة لإعادة الاستخدام + script لتوليد المتغيرات | LES-030404 |
| 6 | `client-presentation.pdf` | عرض تقديمي للعميل (6 شرائح) يوضح عملية التصميم والقرارات | LES-030304, LES-030305 |

> يجب أن تكون الهوية مترابطة تمامًا وتدعم اللغة العربية بقوة.

## 3. سُلَّم التقييم (Rubric)

| المعيار | 4 (ممتاز) | 3 (جيد جدًا) | 2 (مقبول) | 1 (غير مكتمل) |
|---------|-----------|--------------|-----------|----------------|
| **الالتزام بالموجز** | كل التسليمات الستة كاملة ومترابطة بصريًا مع نظام هوية موحد | التسليمات كاملة مع فجوة ترابط بسيطة | تسليم ناقص واحد أو ترابط ضعيف | أكثر من تسليم ناقص أو خارج الموجز |
| **التقنية والمهارة** | تطبيق دقيق للمتجهات + الشبكات الهندسية + الأنماط + التصدير الاحترافي | تطبيق صحيح مع أخطاء طفيفة | تطبيق جزئي للتقنيات | غياب واضح للتقنيات الأساسية |
| **الجودة البصرية** | أعمال احترافية متناسقة الطباعة والألوان والتطبيقات | جيدة مع بعض العيوب البصرية | مقبولة بلا تناسق كبير | أعمال غير مكتملة أو رديئة |
| **التقديم والتوثيق** | دليل هوية كامل + عرض تقديمي مفصل + CREDITS دقيق | دليل كامل مع نقص بسيط في التوثيق | دليل ناقص أو توثيق ضعيف | غياب الدليل أو التوثيق |

## 4. معايير المراجعة الذاتية (قبل التسليم)

- [ ] التسليمات الستة موجودة بالأسماء الصحيحة وفي مجلد `03-التسليم`.
- [ ] الشعار يحتوي على 3 نسخ (أساسي/أحادي/أفقي) ومبني على شبكة هندسية.
- [ ] دليل الهوية يغطي كل العناصر المطلوبة ويوضح الاستخدامات المحظورة.
- [ ] التطبيقات تظهر الهوية على وسائط مختلفة مع تناسق كامل.
- [ ] التصدير يشمل CMYK + Spot + SVG/PNG جاهزة للاستخدام.
- [ ] الأنماط والأتمتة تعمل وتولد متغيرات.
- [ ] عرض العميل يوضح عملية التصميم والقرارات.
- [ ] CREDITS.md يوثق كل الأصول والخطوط.

## 5. إجراءات التسليم

1. جهّز مجلد `03-التسليم` في مشروعك وضع فيه التسليمات الستة + مجلد فرعي `assets`.
2. قدّم رابط/ملفات التسليم عبر منصة التعلم (SCR-11).
3. ستُراجع أعمالك وفق السُلَّم أعلاه خلال 72 ساعة (DOC-08 §8).
4. في حال الإعادة: عالج الملاحظات وقدّم نسخة V2 خلال 3 أيام (DOC-08 §5).
