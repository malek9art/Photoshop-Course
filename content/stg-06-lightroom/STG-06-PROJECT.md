# STG-06-PROJECT — مشروع المرحلة السادسة

> **Content Package:** `project-STG06-v1.0.0` · **Type:** Stage project (AT-05) · **Difficulty:** I2
> **Config:** تقييم بسُلَّم 4 معايير (DOC-08 §6) · النجاح: متوسط ≥ 3.0/4 وعدم وجود أي معيار بدرجة 1 · محاولتان بفاصل 3 أيام

## 1. نبذة المشروع

مشروع المرحلة السادسة يتوّج تعلمك للايتروم بإنتاج **مجموعة مصورة متماسكة (10–15 صورة)** بروح معالجة موحدة (مثل رحلة أو مشروع تصويري). يشمل إدارة الكتالوج، التطوير، الدمج، والتصدير لوجهتين — كما اختتم في LES-060403.

**الفكرة:** تنتج مجموعة صور مترابطة بصريًا (نفس الإعدادات المسبقة والأسلوب) مع تسليم للويب والطباعة.

## 2. المطلوب (Brief)

| # | التسليم | الوصف | المصدر |
|---|---------|-------|--------|
| 1 | `photo-series-catalog.lrcat` | كتالوج لايتروم منظم يحتوي 12–15 صورة أصلية + تصنيف + تقييم + كلمات مفتاحية | LES-060201, LES-060202 |
| 2 | `photo-series-develop.lrtemplate` | إعدادات مسبقة موحدة (Preset) + snapshots لكل مرحلة تطوير | LES-060203, LES-060205 |
| 3 | `photo-series-edited.dng` | 12–15 صورة معالجة (HDR/بانوراما + أقنعة متقدمة + تصحيحات انتقائية) | LES-060301, LES-060302, LES-060303 |
| 4 | `photo-series-bridge.psd` | 3–5 صور محولة إلى فوتوشوب لمعالجة إضافية (كائنات ذكية) | LES-060304 |
| 5 | `photo-export-web.zip` | صور مصغرة + كاملة للويب (JPEG + metadata) + معرض HTML بسيط | LES-060401 |
| 6 | `photo-export-print.zip` | صور جاهزة للطباعة (TIFF 300dpi + ICC) + CREDITS + process-doc.pdf | LES-060401, LES-060402, LES-060403 |

> يجب أن تكون المجموعة مترابطة بصريًا (نفس الـ Preset والأسلوب) وتوثق رحلة أو موضوعًا واضحًا.

## 3. سُلَّم التقييم (Rubric)

| المعيار | 4 (ممتاز) | 3 (جيد جدًا) | 2 (مقبول) | 1 (غير مكتمل) |
|---------|-----------|--------------|-----------|----------------|
| **الالتزام بالموجز** | كل التسليمات الستة كاملة ومترابطة بصريًا مع Preset موحد | التسليمات كاملة مع فجوة ترابط بسيطة | تسليم ناقص واحد أو ترابط ضعيف | أكثر من تسليم ناقص أو خارج الموجز |
| **التقنية والمهارة** | تطبيق دقيق للكتالوج + التطوير + الدمج + الأقنعة + التصدير المتعدد | تطبيق صحيح مع أخطاء طفيفة | تطبيق جزئي للتقنيات | غياب واضح للتقنيات الأساسية |
| **الجودة البصرية** | مجموعة متماسكة احترافية متناسقة الإضاءة والألوان | جيدة مع بعض العيوب البصرية | مقبولة بلا تناسق كبير | مجموعة غير مكتملة أو رديئة |
| **التقديم والتوثيق** | تسليم مهني كامل + وثيقة عملية مفصلة + CREDITS دقيق | تسليم كامل مع نقص بسيط في التوثيق | تسليم ناقص أو توثيق ضعيف | غياب التسليم أو التوثيق |

## 4. معايير المراجعة الذاتية (قبل التسليم)

- [ ] التسليمات الستة موجودة بالأسماء الصحيحة وفي مجلد `06-التسليم`.
- [ ] الكتالوج منظم ويحتوي تصنيفًا وكلمات مفتاحية.
- [ ] الـ Preset موحد ويطبق على كل الصور.
- [ ] الدمج (HDR/بانوراما) والأقنعة المتقدمة واضحة.
- [ ] التصدير لويب يشمل JPEG + metadata + معرض HTML.
- [ ] التصدير للطباعة يشمل TIFF 300dpi + ICC.
- [ ] process-doc.pdf يوثق سير العمل والقرارات.
- [ ] CREDITS.md يوثق كل الصور والمصادر.

## 5. إجراءات التسليم

1. جهّز مجلد `06-التسليم` في مشروعك وضع فيه التسليمات الستة + مجلد فرعي `assets`.
2. قدّم رابط/ملفات التسليم عبر منصة التعلم (SCR-11).
3. ستُراجع أعمالك وفق السُلَّم أعلاه خلال 72 ساعة (DOC-08 §8).
4. في حال الإعادة: عالج الملاحظات وقدّم نسخة V2 خلال 3 أيام (DOC-08 §5).
