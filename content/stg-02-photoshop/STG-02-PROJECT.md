# STG-02-PROJECT — مشروع المرحلة الثانية

> **Content Package:** `project-STG02-v1.0.0` · **Type:** Stage project (AT-05) · **Difficulty:** A1
> **Config:** تقييم بسُلَّم 4 معايير (DOC-08 §6) · النجاح: متوسط ≥ 3.0/4 وعدم وجود أي معيار بدرجة 1 · محاولتان بفاصل 3 أيام

## 1. نبذة المشروع

مشروع المرحلة الثانية يتوّج تعلمك لفوتوشوب بإنتاج **حملة بصرية متكاملة** لمنتج (مثل عطر أو جهاز إلكتروني أو مشروب). يجمع بين التنقيح الاحترافي، التركيب الواقعي، التصميم للوسائط الاجتماعية، والتسليم المهني — كما بدأ في LES-020504.

**الفكرة:** تنتج مجموعة ملفات مترابطة بصريًا (هوية لونية موحدة، أسلوب واحد) تُظهر إتقانك لسير العمل غير الهدّام، الأقنعة، أوضاع المزج، والأتمتة.

## 2. المطلوب (Brief)

| # | التسليم | الوصف | المصدر |
|---|---------|-------|--------|
| 1 | `campaign-product-retouch.psd` | صورة المنتج الأصلية بعد تنقيح احترافي (إصلاح، استنساخ، فصل ترددات، تدرج ألوان) مع طبقات منظمة وأقنعة | LES-020201, LES-020202, LES-020203, LES-020204, LES-020205 |
| 2 | `campaign-hero-composite.psd` | مشهد مركب واقعي (منتج في بيئة جذابة) باستخدام الأقنعة المتقدمة وأوضاع المزج والظلال/الإضاءة | LES-020301, LES-020302, LES-020305, LES-020306 |
| 3 | `social-posts-pack.zip` | 6 منشورات (3 مقاسات: 1080×1080, 1080×1920, 1200×628) + ماكيتات ونماذج للمنتج | LES-020401, LES-020402, LES-020403 |
| 4 | `campaign-brand-kit.ai` | ملف Illustrator يحتوي الشعار المبسط + لوحة ألوان + أنماط (مستورد من فوتوشوب) | LES-020503 |
| 5 | `delivery-package.zip` | مجلد تسليم مهني: PSDs + PNGs + PDF + README + CREDITS + action set للأتمتة | LES-020406, LES-020502, LES-020504 |
| 6 | `campaign-process.pdf` | وثيقة PDF (4 صفحات) توثق سير العمل (قبل/بعد + قرارات التصميم + ملاحظات العميل المحاكاة) | LES-020501, LES-020504 |

> يجب أن تكون جميع التسليمات مترابطة بصريًا (نفس الهوية اللونية 60/30/10) وتحمل اسم الحملة (مثل "Aether Perfume 2026").

## 3. سُلَّم التقييم (Rubric)

| المعيار | 4 (ممتاز) | 3 (جيد جدًا) | 2 (مقبول) | 1 (غير مكتمل) |
|---------|-----------|--------------|-----------|----------------|
| **الالتزام بالموجز** | كل التسليمات الستة كاملة ومترابطة بصريًا مع هوية موحدة | التسليمات كاملة مع فجوة ترابط بسيطة | تسليم ناقص واحد أو ترابط ضعيف | أكثر من تسليم ناقص أو خارج الموجز |
| **التقنية والمهارة** | تطبيق دقيق للتنقيح غير الهدّام + الأقنعة المتقدمة + أوضاع المزج + الأتمتة | تطبيق صحيح مع أخطاء طفيفة | تطبيق جزئي للتقنيات | غياب واضح للتقنيات الأساسية |
| **الجودة البصرية** | أعمال احترافية واقعية متناسقة الألوان والإضاءة | جيدة مع بعض العيوب البصرية | مقبولة بلا تناسق كبير | أعمال غير مكتملة أو رديئة |
| **التقديم والتوثيق** | تسليم مهني كامل + وثيقة عملية مفصلة + CREDITS دقيق | تسليم كامل مع نقص بسيط في التوثيق | تسليم ناقص أو توثيق ضعيف | غياب التسليم المهني أو التوثيق |

## 4. معايير المراجعة الذاتية (قبل التسليم)

- [ ] التسليمات الستة موجودة بالأسماء الصحيحة وفي مجلد `03-التسليم`.
- [ ] الهوية اللونية موحدة عبر جميع القطع (60/30/10 موثقة).
- [ ] التنقيح غير الهدّام وفصل الترددات مطبقان في campaign-product-retouch.psd.
- [ ] الظلال والإضاءة الواقعية واضحة في campaign-hero-composite.psd.
- [ ] المنشورات الاجتماعية جاهزة للنشر بثلاثة مقاسات.
- [ ] action set + brand-kit مستوردان ويعملان.
- [ ] delivery-package يحتوي README + CREDITS + ملفات PDF.
- [ ] campaign-process.pdf يوثق قرارات التصميم وسير العمل.

## 5. إجراءات التسليم

1. جهّز مجلد `03-التسليم` في مشروعك وضع فيه التسليمات الستة + مجلد فرعي `assets`.
2. قدّم رابط/ملفات التسليم عبر منصة التعلم (SCR-11).
3. ستُراجع أعمالك وفق السُلَّم أعلاه خلال 72 ساعة (DOC-08 §8).
4. في حال الإعادة: عالج الملاحظات وقدّم نسخة V2 خلال 3 أيام (DOC-08 §5).
