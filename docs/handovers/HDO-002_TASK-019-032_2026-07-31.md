## 10. Lessons Learned

1. Registry documents work best when each names its authority and its update rules explicitly (LESSONS_INDEX → DOC-03; OPEN_DECISIONS → DOC-14).
2. Snapshots (PROJECT_STATE) must always cite their authoritative source to avoid becoming a second truth.
3. Generating the 156-row lesson table from DOC-03 programmatically eliminated transcription errors — the same approach should be used for future content registries.
4. Version discipline (1.0.0 → 1.0.1/1.1.0) applied consistently across the extension kept the changelog fully reconcilable (CHG-002).
