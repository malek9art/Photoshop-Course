## 10. Lessons Learned

1. The 12-element lesson template scales well; frontmatter consistency is the main repetition cost — tooling will help (KBE-009).
2. Quiz pools of 16 items per module are feasible and satisfy DOC-07 §5.3; keep the pool ≥ 2× for all future modules (KBE-010).
3. Declaring appVersion per lesson early avoids retro-edits, but the baseline must be re-verified at media production (KBE-011).
4. Working within DOC-32 scope discipline was straightforward because the scope table (28 lessons) maps 1:1 to DOC-22 rows — keep this pattern for MS-03+.
5. User-directed waivers must be documented visibly (DEP-017, CHG-004) so future agents don't assume TASK-102/101 were completed.
