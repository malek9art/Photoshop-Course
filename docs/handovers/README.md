# Handovers Index

This folder stores all completed agent handovers (`HDO-NNN`). See `docs/12_AGENT_HANDOVER.md` for the policy.

## Naming convention

```
HDO-NNN_<TASK-ID>_<YYYY-MM-DD>.md
```

## How to register a handover

1. Copy `docs/templates/HANDOVER_TEMPLATE.md` here with the next free HDO number.
2. Fill all ten sections (policy: `docs/12_AGENT_HANDOVER.md` §3).
3. Add a row to the index table below.
4. Link the HDO ID in the task's Notes (`docs/11_TASK_MANAGEMENT.md`).
