1. Phase transitions need a *gate record* (GATE-F1 PASS), not just a status flip — it gives future agents an auditable answer to "was the foundation actually approved?".

4. Coordinated version bumps across 20+ documents stay reconcilable when each document's revision history is updated in the same change and the changelog entry lists every version transition.
