### المواصفات الإلزامية لكل ملف

1. **العنوان:** `# STG-0X-PROJECT — مشروع المرحلة ...` (المحلل يقرأ أول سطر `#`).
2. **سطري الإعدادات:**
   ```
   > **Content Package:** `project-STG0X-v1.0.0` · **Type:** Stage project (AT-05) · **Difficulty:** XX
   > **Config:** تقييم بسُلَّم 4 معايير (DOC-08 §6) · النجاح: متوسط ≥ 3.0/4 وعدم وجود أي معيار بدرجة 1 · محاولتان بفاصل 3 أيام
   ```
   (الصعوبات: STG-02 A1 · STG-03 A2 · STG-04/05 I1 · STG-06 I2 · STG-07 A2 · STG-08 A3)
3. **الأقسام الخمسة** بنفس ترتيب STG-01: `## 1. نبذة المشروع` · `## 2. المطلوب (Brief)` جدول تسليمات مُسمّاة بأسماء ملفات دقيقة مع عمود «المصدر» يشير لرموز LES الفعلية · `## 3. سُلَّم التقييم (Rubric)` · `## 4. معايير المراجعة الذاتية (قبل التسليم)` checkboxes · `## 5. إجراءات التسليم` · ثم `**Revision History**` (Version 1.0.0 · 2026-08-01 · AGT-003).
4. **جدول الروبرك — قيود المحلل `app/src/lib/rubric.ts` (حرجة):**
   - صف الترويسة يجب أن يبدأ حرفياً بـ `| المعيار |` (يطابق `/^\|\s*المعيار\s*\|/`).
   - الأعمدة: `| المعيار | 4 (ممتاز) | 3 (جيد جدًا) | 2 (مقبول) | 1 (غير مكتمل) |` ثم صف فاصل `|---|...`.
   - كل صف معيار: اسم بين `**…**` + 4 خلايا وصف. **لا تستخدم أعمدة إضافية ولا سطوراً فارغة داخل الجدول.**
   - يجب أن يستخرج المحلل 4 معايير بالضبط لكل مشروع. قاعدة النجاح البرمجية: متوسط ≥ 3.0 **و** لا معيار = 1 (`rubricVerdict`).
5. **أهداف قابلة للقياس:** كل تسليمة في Brief لها اسم ملف + وصف + مصدر LES؛ المحتوى عربي فصيح نظيف بلا نصوص عامة ولا عناصر نائبة.

### التحقق (أعد إنشاء السكربت — `/tmp` لا يُحفظ بين الجلسات):

```bash
cat > /tmp/qa-rubric.ts << 'EOF'
import { loadProjectRubric } from "/home/user/Photoshop-Course/app/src/lib/rubric";
let ok = true;
for (const code of process.argv.slice(2)) {
  const doc = loadProjectRubric(code);
  if (!doc) { console.log(`✗ ${code}: not found`); ok = false; continue; }
  const bad = doc.criteria.filter(c => !c.name || !c.d4 || !c.d3 || !c.d2 || !c.d1);
  console.log(`${doc.criteria.length === 4 && bad.length === 0 ? "✓" : "✗"} ${code}: criteria=${doc.criteria.length} bad=${bad.length} title="${doc.title}"`);
  if (doc.criteria.length !== 4 || bad.length) ok = false;
}
process.exit(ok ? 0 : 1);
EOF
cd app && npx tsx /tmp/qa-rubric.ts STG-02-PROJECT STG-03-PROJECT STG-04-PROJECT STG-05-PROJECT STG-06-PROJECT STG-07-PROJECT STG-08-PROJECT
```
